Introduction
In this course, you'll learn about Earned Value Management (EVM), discover how to gauge project performance accurately and use this information to make strategic decisions for project success. You'll also learn how to implement PMP formulas, equipping you with the tools to monitor progress and optimize resource utilization across diverse project environments.

Additionally, you'll learn how to assess project financial Return on Investment (ROI), honing your ability to evaluate project feasibility and prioritize investments to maximize organizational value.

By the end of this course, you will be able to:

Describe the process of EVM.

Implement the PMP formulas project environments.

Assess if a project has a sound financial ROI.

Prerequisites
Whether you’re new to project management or hoping to enter this field, this learning journey may be just what you need to achieve your goals. Previous experience in project management or related areas is not necessary to pursue this certification; however, some familiarity with Microsoft apps would be beneficial, although it is not required.

Let’s take a moment to outline what you’ll cover as you progress through this course.

Module 1: Introduction to PMP formulas
This module provides a comprehensive overview of Earned Value Management (EVM) and cost management. You'll learn about essential PMP formulas and how to apply them to evaluate project performance and manage costs throughout the project lifecycle. You will be introduced to EVM Variance Analysis and Forecasting, where you will learn how to calculate and interpret key project metrics and performance indicators through practical examples. From understanding formula concepts to hands-on calculations, you will gain the expertise to utilize PMP formulas effectively.

After completing this module, you'll be able to:

Identify key PMP formulas.

Discuss the application of PMP formulas to project scenarios.

Identify how to calculate project metrics.

Module 2: Scheduling and estimating
In this module, you will explore and apply essential schedule management formulas within the context of project management, enabling you to plan, monitor effectively, and control project schedules. This session covers the Critical Path Method (CPM), Schedule Variance (SV), Schedule Performance Index (SPI), and other relevant formulas for comprehensive schedule and estimation management.

After completing this module, you'll be able to:

Identify the CPM and its calculation steps.

Discuss and interpret SV.

Identify best practice schedule management formulas.

Module 3: Investment analysis and procurement
In this module, you will apply key investment analysis & procurement management formulas, equipping you with the skills to appraise project investment opportunities. You’ll also explore essential concepts, techniques, and strategies for assessing project investment and procurement.

After completing this module, you'll be able to:

Identify project investment appraisal techniques and their applications.

Discuss procurement formulas and relevant processes.

Identify PMP investment and procurement management formulas.

Module 4: Final project and assessment
In this module, you’ll put your skills into practice. You’ll reflect on the key learning points that you reviewed during the course and complete the final assessment and hands-on activity.

After completing this module, you'll be able to:

Synthesize the skills from this course by completing a graded assessment.

Reflect on this course's content and the learning path ahead.

Conclusion
Upon completing this course, you will gain a deeper understanding of the formulas used in PMP and how to apply them as a project manager. You use EVM to gauge project performance accurately and make strategic decisions for project success. By implementing PMP formulas, you will have the tools to monitor progress and optimize resource utilization across various project environments.

Additionally, you will learn to assess project financial ROI, enhancing your ability to evaluate feasibility and prioritize investments to maximize value for your organization. This course offers a comprehensive overview of essential concepts and skills for both beginners and experienced project and program managers seeking to deepen their expertise in managing successful initiatives.
