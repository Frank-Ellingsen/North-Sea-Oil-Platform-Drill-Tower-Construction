Graph components
When creating an S-Curve performance is plotted across project time on the horizontal axis (X-axis) and project cost on the vertical axis (Y-axis). The status date (also called the point of stoppage), represented by the first vertical dotted line on this graph, denotes the point of performance measurement in EVM. Each curved line represents a key component of EVM. Specifically:

The top curve represents the Actual Cost (AC), also known as the Actual Cost for Work Performed (ACWP)

The middle curve represents the Planned Value (PV), also known as the Authorized Budgeted Cost for Work Scheduled (BCWS).

The bottom curve represents Earned Value (EV), also known as the Budgeted Cost of Work Performed (BCWP)

The dashed horizontal lines and vertical arrows function as guides to visualize any variations between the PV, EV, and AC at the status date, specifically Schedule Variance (SV) and Cost Variance (CV).

Graph inferences
The PV, EV, and AC lines offer a visual representation of how the project is tracking compared to the project plan. What do the PV, EV, and AC lines tell us about the project?

In the graph, EV is below PV, implying that this project has generated a comparatively lesser value than what was originally planned. AC is above PV, which implies that this project has consumed more money than what was originally planned (PV). Therefore, you can infer that this project has shown poor performance both in terms of Cost and Schedule.

The position of the curved lines also indicates the CV and SV.

As you learned previously, CV is the difference between EV and AC (CV = EV – AC). Cost variance is evident on the graph, represented by the differences in the position of the EV and AC lines at the status date (cost variance arrow). At the stopping point (status date), as the EV is lower than the AC, you can infer that there is a negative variance in terms of cost.

SV is the difference between EV and PV (SV = EV – PV). The SV for this imaginary scenario is also negative because, as per the graph, the EV is less than the PV, Therefore, you infer that there is variance in this project (represented by the schedule variance arrow in the graph), and it is a negative variance in terms of schedule.

With a better picture of how the project has been performing, this project now calls for Forecasting to adjust for the deviations, which you will learn about in the next lesson.

Along with CV and SV, you learned about two other performance metrics for measuring project performance in the previous video. CPI is the ratio of EV by AC (CPI = EV / AC). If the CPI value is less than 1 or greater than 1, it indicates that the project is underperforming (cost overrun) or performing well (under budget), respectively. SPI is the ratio of EV by PV (SPI = EV / PV). If the SPI value is less than 1 or greater than 1, it indicates that the project’s performance is bad (behind schedule) or good (ahead of schedule), respectively.

Understanding CV and SV using an example scenario
Project scenario
You are managing your company’s end-of-year charity fundraiser. The project has a baseline budget of $100,000 and a baseline schedule of 40 weeks. The baseline indicates that by the end of week 20, the project is planned to be 50% complete. As of the end of week 20, it is reported that 40% of the project work had been completed at a cost of $60,000. You decide to measure and understand the project’s performance so far.

As a project manager, your task would be to use the EVM method to perform Variance Analysis and report on the project’s performance at the status date (end of 20 weeks). The sections that follow outline how to calculate the Cost Variance (CV), Schedule Variance (SV), Cost Performance Index (CPI), and Schedule Performance Index (SPI) using their respective formulas.

Variance Analysis metrics and formulas
CV = EV – AC

SV = EV – PV

CPI = EV / AC

SPI = EV / PV

Where:

PV = Planned Value

EV = Earned Value

AC = Actual Cost

Calculations
The formulas for the performance metrics make use of Actual Cost (AC), Planned Value (PV), and Earned Value (EV). AC is given. You will need to calculate EV and PV.

Metric

Calculation

AC

$60,000.00 (given)

PV

At the end of 20 weeks, the project was planned to be 50% completed. The project should have consumed only 50% of the total cost (BAC). Therefore, PV = 50% of BAC. PV = 50% \* $100,000.00 PV = $50,000.00

EV

The project performed only 40% of its work in actuals. Therefore, EV = 40% of BAC. EV = 40% \* $100,000.00 EV = $40,000.00

Using this information, you can now calculate the CV, SV, CPI, and SPI metrics.

CV = EV – AC = $40,000 – $60,000 = -$20,000

SV = EV – PV = $40,000 – $50,000.00 = -$10,000

CPI = EV / AC = $40,000 / $60,000 = 0.67

SPI = EV / PV = $40,000 – $50,000 = 0.8

Analysis and interpretation (inferences)
The charity fundraiser project has shown a negative variance in terms of both cost and schedule, with a CV of -$20,000 (CV < 0) and an SV of -$10,000 (SV < 0). The project has undergone a cost overrun and a schedule delay situation. The project’s current performance rate is 0.6 for cost (CPI < 1) and 0.8 for schedule (SPI < 1). As both indices are less than 1, the project is performing poorly.

While variance quantifies and tells you the difference in exact numbers ($), the index depicts the speed (rate) at which the project performs. This information enables the project manager to do deep investigations into who, when, where, and why the variances were caused.
