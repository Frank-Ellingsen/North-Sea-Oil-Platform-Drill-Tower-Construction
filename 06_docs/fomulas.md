Let’s discuss how each of these phases and their outputs relates to EVM and cost management.

Planning
The output of the Planning phase is the Project Management Plan, which includes all the approved baselines. The scope, schedule, and cost baselines are foundational components of EVM. These baselines contain the original, approved estimates that are used to evaluate a project’s performance as it progresses. Specifically:

The scope baseline contains the Work Breakdown Structure (WBS), which outlines the project work and deliverables.

The schedule baseline contains the overall estimated project duration.

The cost baseline contains the overall project cost.

Execution
In the Execution phase, the activities on the project schedule are implemented. It also generates work performance data as output, which contains details on the actual work completed. Examples of the output include the list of activities executed; the date each activity was completed; the actual time spent completing each activity; and the actual cost consumed by each activity. This output is essential for conducting EVM in the next phase of the project lifecycle.

Monitoring and Controlling (M&C)
The M&C phase measures performance through EVM by comparing the plan (baselines) with the actuals (work performance data). EVM is a comprehensive project management methodology that contrasts scope, schedule, and cost variables to provide an accurate picture of project performance and progress.

By comparing planned work with the work that’s actually been completed work (referred to as plan versus actuals), EVM allows project managers to identify and analyze variances. Using EVM forecasting, project managers can estimate future performance based on the current performance and implement corrective measures as needed. The focus of this reading is the key components and Variance Analysis metrics and performance indices in EVM. You will learn about forecasting metrics and formulas later in this module.

EVM metrics and formulas
To measure and analyze performance using EVM, project managers will need to determine key dimensions of measurements and calculate various performance metrics. You’ll learn about these in detail in this module and their role in EVM calculations and cost management. You may find it helpful to use this outline as a reference as you progress through your lessons.

An outline of key dimensions of measurement and Variance Analysis metrics in EVM is provided below.

Dimensions of measurement
EVM is a technique that develops three key dimensions to measure and monitor the scope, schedule, and cost performance for every work package (group of similar activities) in the Work Breakdown Structure (WBS). These three dimensions of measurement, Planned Value, Earned Value, and Actual Cost, are outlined below.

Budget at Completion (BAC)
BAC is the total budget allocated for the project. BAC serves as the baseline for measuring project performance and calculating key EVM metrics.

Formula: Sum of all Planned Values

Planned Value (PV)
PV is the authorized budget (baseline value) assigned to the scheduled project work.

PV = Budgeted Cost of Work Scheduled (BCWS)

Earned Value (EV)
EV is the value earned by executing an activity, expressed in terms of the budget assigned to that work.

EV = Budgeted Cost of Work Performed (BCWP)

Actual Cost (AC)
AC is the cost consumed by the work performed on a scheduled activity or a WBS component.

AC = Actual Cost of Work Performed (ACWP)

Budget at Completion (BAC)
BAC is the total budget allocated for the project. BAC serves as the baseline for measuring project performance and calculating key EVM metrics.

Formula: Sum of all Planned Values

Performance metrics
By comparing planned and completed work in EVM, performance metrics give the project manager insight into actual project performance. These metrics and their formulas are:

Cost Variance (CV)
CV is the difference between EV and AC.

Formula: CV = EV – AC

CV > 0, indicates the project is under budget (cost savings and good performance)

CV < 0, indicates the project is over budget (cost overrun and poor performance)

Schedule Variance (SV)
SV is the difference between EV and PV.

Formula: SV = EV – PV

SV > 0, indicates the project is ahead of schedule,

SV < 0, indicates the project is behind schedule

Cost Performance Index (CPI)
CPI measures the cost efficiency of budgeted resources by comparing EV to AC.

Formula: CPI = EV / AC

CPI > 1, indicates cost efficiency (under budget)

CPI < 1, indicates cost inefficiency (over budget)

Schedule Performance Index (SPI)
SPI measures schedule efficiency by comparing EV to PV.

Formula: SPI = EV / PV

SPI > 1, indicates schedule efficiency (ahead of schedule)

SPI < 1, indicates schedule inefficiency (behind schedule)

Variance Analysis metrics and performance indices

Using the dimensions of measurements and performance metrics, the Project Manager analyzes any variations between the plan and actuals for insight into the effect of the variance on cost and schedule efficiency, and project progress. The Variance Analysis metrics and performance indices and their formulas are:

Schedule Variance (SV)
SV is a measure of schedule performance on a project. It is the difference between the EV and PV.

Formula: SV = EV – PV

A negative SV indicates the project is behind schedule, while a positive SV indicates the project is ahead of schedule)

Cost Variance (CV)
CV is a measure of cost performance on a project. It is the difference between the EV and the AC.

Formula: CV = EV – AC

A negative CV indicates budget overrun, while a positive CV indicates that the project is within budget.

Schedule Performance Index (SPI)
SPI is a measure of schedule efficiency expressed as a ratio of EV to PV

Formula: SPI = EV / PV

SPI < 1, indicates less work was completed than planned (bad performance)

SPI > 1, indicates more work was completed than planned (good performance)

Cost Performance Index (CPI)
Definition: A measure of cost efficiency of budgeted resources, expressed as a ratio of EV to AC

Formula: CPI = EV / AC

CPI < 1, indicates cost overrun for work completed (bad performance)

CPI > 1, indicates cost underrun for work completed (good performance)

Note: When CPI and SPI are equal to 1 (CPI = SPI = 1), the project is performing as planned without any variance.

Conclusion
EVM and cost management are integral to the cost control process in the M&C project phase. As a project manager, the metrics and formulas mentioned in this reading can assist with measuring project performance and success.
